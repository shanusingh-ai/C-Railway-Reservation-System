# 🚆 Railway Reservation System

A console-based Railway Reservation System developed in **C Programming Language**. This project allows users to book train tickets, search reservations, cancel bookings and manage passenger records using file handling.

---

## 📌 Project Overview

The Railway Reservation System is designed to simplify railway ticket booking operations through a menu-driven interface. The system stores booking records in files and provides functionalities for ticket management.

This project demonstrates the practical implementation of:

* Structures in C
* Functions
* File Handling
* Menu-Driven Programming
* Data Management

---

## ✨ Features

### 🚉 View Train Details

* Display all available trains
* Show source and destination stations
* Display fare information

### 🎫 Book Ticket

* Select train
* Enter passenger details
* Generate unique Booking ID
* Calculate total fare automatically

### 🔍 Search Booking

* Search bookings using Booking ID
* Display complete ticket information

### ❌ Cancel Booking

* Cancel existing reservations
* Confirmation before deletion

### 📋 View All Bookings

* Display all stored bookings
* Show passenger and ticket details

### 💾 Persistent Storage

* Booking records are stored using file handling
* Data remains available until manually deleted
